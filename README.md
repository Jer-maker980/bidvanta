# BidVanta

BidVanta is an early-stage UK public tender discovery and suitability prototype.

Deployment: Cloudflare Pages, connect this GitHub repository with build command left blank and output directory `/`. Cloudflare Pages Functions are in `functions/api/tenders.js`.

This is a beta. Live government tender retrieval and scoring must be verified before commercial use. No fictional demo tenders should be presented as live data.
